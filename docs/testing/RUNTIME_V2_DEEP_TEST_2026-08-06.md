## 二、新发现(按重要性)

### 🔴 P0(已修复并验证):心跳"思考后沉默"被判成失败
- **现象**:haiku 心跳 4/4 全部 failed,失败码 `malformed_self_thinking_suppressed`,
  且每次失败都写指数退避 → **主动消息会越来越少直至消失**。
- **根因**:自述思考解析器把「干净 `<think>…</think>` + 空正文」判为 FAILED。
  这在聊天里对(用户问了必须答),但在心跳里,**"想了想,决定不打扰"正是产品要的
  正确行为**。07-31 把思考机制扩展到唤醒 lane 时原样复用了聊天的判据(b54a8b79)。
- **为什么六天没被发现**:要同时满足"模型听话写 think 块"+"选择沉默"——
  deepseek 常不写 think 块(走老路径无事),**claude 系又听话又真会沉默,精准踩中**;
  且 prod 当时因 dream 事故已全切 V1,无人在生产踩到;症状对用户不可见
  (失败和沉默看起来都是"没消息")。
- **修复**:codex4 `2f187175` 拆出独立 SILENT 状态,唤醒=合法沉默、聊天=仍必答、
  定时提醒=仍必达。我复验:93 单测 + haiku 实弹心跳 **3/3 completed、零退避**。

### 🟠 真 parity 缺口:世界书(World Book)在 V2 整条没接 —— 修复打回中
- **事实**:iOS 有完整功能(seal + list/upsert/delete,21 条文案),后端接口齐备,
  **V1 每轮前台聊天注入**;`grep -rni "world" backend/model_api_runtime/` 零命中。
- **后果**:V2 用户认真写的世界书条目**每一轮都不生效,且完全无声**——
  表现为"AI 不认识我设定的世界观",不像功能坏了。parity 矩阵也漏登记。
- **进展**:已派 codex4 → 他交付 `dddd9a29`(独立 UNTRUSTED user 块注入、24k 上限、
  截断有标记、不改写用户原消息)→ **我 gatekeep 打回**:他自己新增的用例
  `test_chat_worldbook_matches_current_turn_without_rewriting_user_text` 在 CI
  (run 31046395056)红,我本机 det=0/1 两态都复现红;test 部署 pin 因此停在
  `eb74f17`,世界书还没上 test。已要求他先说清是实现问题还是用例问题、
  **不许直接改断言变绿**。
- **我的 live 验证目前未完成**:本地 rig 建不了世界书条目(客户端封装的信封被
  enclave 判 unavailable),判断是本地 rig 对"客户端封装内容"这条路的支持缺口,
  不是实现问题。等 CI 转绿、部署到位后我在 test 部署态补跑。

## 五、我改了什么(逐条:改动 + 为什么)

**只改测试设施,没有碰任何产品代码。**后端改动全部由 codex4 做、我 gatekeep。

1. `tools/e2e/probe_common.py` — 探针写记忆的 source 从 `e2e_probe` 改成真实产品
   source `memory_capture`。**原因**:写入路有 source 白名单,`e2e_probe` 不在其中,
   导致 deep memory 区 8 格挂 7 格全报 400,看起来像产品坏了。**没有**把测试值加进
   白名单——那会削弱这道校验本身。(commit `0bc83c34`)
2. `tools/e2e/continuity_probe.py` — 幂等用例从"固定 sleep 4 秒后数行"改成
   "轮询到期 + 拿到 1 行后再等 5 秒看有没有迟到的重复行"。**原因**:异步 ingest +
   部署窗 → 假阳性 PRODUCT_FAIL;改法既去假阳性,也不放过真重复。(同上 commit)
3. 新增四个本地 rig 探针(commit `62c8bc66`):`switch_matrix_probe`(开关独立性)、
   `wake_write_gate_probe`(wake 写权限分档)、`perception_wake_probe`(感知链四不变量
   + 跨进程一致性)、`idempotency_probe`(消息重复两族)。**原因**:这四面都是
   `docs/testing` 矩阵点名"必做"、但此前没有自动化覆盖的;这轮又恰好都动过
   (DND 闸动了调度查询、wake lane 动了 prompt 与沉默语义、PR#158 重造了感知链)。
   全部只打本地 rig / 纯静态,不碰 test/prod。

**注意**:我做这些改动时 codex4 正在同一棵树上写世界书,我全程只 `git add` 我自己的
文件,没有把他的半成品带进任何 commit(他也确认没动我的两个探针文件)。
