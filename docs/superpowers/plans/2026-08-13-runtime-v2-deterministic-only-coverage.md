# Runtime V2 Deterministic-Only Coverage Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove Runtime V2 provider-backed conversation summarization and its rollout switch so every new leaf and checkpoint is a metadata-only deterministic coverage sentinel.

**Architecture:** Keep immutable summary rows and exact seq/count provenance, but make their write path single-mode. Maintenance and inline catch-up read only coverage metadata; frontier roll-up derives parent text only from trusted metadata, including legacy opaque children, while existing historical encrypted text remains readable until a new parent replaces it in the canonical frontier.

**Tech Stack:** Python 3.12, asyncio, PostgreSQL/psycopg, pytest, Docker Compose YAML, GitHub Actions YAML, Fumadocs/Next.js documentation.

## Global Constraints

- MEMORY/USER profile is the only long-term semantic layer; do not add a conversation-summary fallback.
- Raw encrypted `chat_messages` remain the durable source ledger; summary coverage never authorizes deletion.
- Do not migrate, update, or delete existing `v2_conversation_summary_segments` rows.
- Historical model-authored segments remain readable, but every new parent discards child prose and uses metadata-only coverage text.
- No Runtime V2 conversation-compaction path may resolve or call a provider, decrypt old chat rows, or render old chat content.
- Exact coverage, CAS ownership, lease fencing, runtime-mode fencing, and watermark integrity remain fail-closed.
- Do not change profile generation, profile encryption, tail replay turn limits, tail anchoring, or coverage-hole behavior.
- Do not regenerate OpenAPI because no HTTP contract changes.
- Ordinary development targets `test`, never `main` directly.

---

## File Structure

- `backend/model_api_runtime/v2/compaction.py`: retain only local coverage-sentinel rendering; remove provider prompts, parsing, verbatim folding, and async semantic APIs.
- `backend/model_api_runtime/v2/summary_frontier.py`: choose roll-up candidates by structural/count and materialized-frontier bounds, never provider input size.
- `backend/model_api_runtime/v2/worker.py`: make maintenance, inline catch-up, and checkpoint roll-up metadata-only; remove semantic retry/quarantine/config branches and let maintenance skip provider setup.
- `backend/model_api_runtime/v2/serve_worker.py`: expose metadata-only frontier assembly and remove semantic-compaction production seams.
- `backend/db.py`: remove the now-unused effective semantic batch-cap accessors; retain the historical database column because this change performs no migration.
- `tests/test_v2_deterministic_compaction.py`: become the main fixed-contract integration suite.
- `tests/test_v2_summary_frontier_unit.py`: lock mixed historical/deterministic metadata-only roll-up.
- `tests/test_v2_compaction*.py`, `tests/test_v2_prompt_invariant.py`, and adjacent Runtime V2 tests: delete semantic-only cases and update call signatures without weakening coverage/CAS/lease assertions.
- `.github/workflows/ci.yml`, `deploy/docker-compose.phala*.yaml`: remove rollout, char-budget, and quarantine variables and collapse the compaction matrix.
- `docs-site/content/docs/self-hosting.mdx`, `docs-site/content/docs/changelog.mdx`, `docs/RUNTIME_V2_FLOWS.md`, `docs/CHANGELOG.md`: publish the single-path contract and remove rollback guidance.

```python
def deterministic_fold(
    *,
    source_message_count: int,
    includes_legacy_opaque: bool = False,
) -> str:
    count = int(source_message_count)
    if count < 0 or (count == 0 and not includes_legacy_opaque):
        raise ValueError("source_message_count must prove coverage")
    if includes_legacy_opaque and count == 0:
        return "- [更早的历史摘要已由长期记忆覆盖]"
    if includes_legacy_opaque:
        return f"- [更早的历史摘要及 {count} 条消息已由长期记忆覆盖]"
    return f"- [{count} 条更早的消息已由长期记忆覆盖]"
```
